# Inspect Vehicles Entering The Agency

As an employee, I want to inspect vehicles entering the premises to assess their mechanical condition and determine whether they meet the requirements for purchase or sale.
This ensures that only cars in safe and road-legal condition are traded.

## Acceptance criteria

* The system must allow for the registration of a vehicle entering the lot for inspection.
* The employee must be able to record vehicle identification details, such as make, model, year, serial number, and mileage.
* The system must allow for recording the vehicle's mechanical, exterior, and interior condition.
* The system must allow for recording faults, damage, photographs, and inspection observations.
* The system must allow for indicating whether the vehicle is approved, rejected, or requires further review.
* The system must prevent an inspection from being saved if mandatory fields are missing.
* The system must allow for viewing the inspection history of each vehicle.
* The system must notify the employee if a vehicle with the same serial number is already registered.

## Definition of done

* [ ] Vehicle and inspection registration has been implemented.
* [ ] Vehicle condition assessment and its result have been implemented.
* [ ] Validation of mandatory fields and duplicate serial numbers has been tested.
* [ ] Inspection history lookup has been verified.
