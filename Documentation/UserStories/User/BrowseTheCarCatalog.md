# Browse the car catalog

As a User, I want to see the list of cars available for sale
So that I can find one that fits my needs.

The catalog is the dealership's showroom and the starting point of almost every sale. It can be browsed without logging in to attract more customers.

## Acceptance criteria

* The system shows only cars with status “Available”.
* The system never shows cars with status “Sold”, “Reserved” or “Spare parts”.
* The system shows each car's photo, brand, model, year, mileage and price.
* The system paginates results 20 at a time.
* The system shows a message when no cars are available.
* The system allows browsing the catalog without logging in.
