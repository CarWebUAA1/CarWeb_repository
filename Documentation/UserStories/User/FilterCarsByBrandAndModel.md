#  Filter cars by brand and model

As a User, I want to filter the catalog by brand and model
So that I don't have to look through cars I'm not interested in
As the catalog grows. 

Finding a specific car by scrolling becomes slow. The filter helps the customer reach the car they want faster.

## Acceptance criteria

* The system allows filtering by brand, by model, or by both.
* The system shows only available cars that match the filter.
* The system ignores upper/lower case and accents when searching.
* The system shows “No cars match your search” and lets the user clear the filter when there are no results.
