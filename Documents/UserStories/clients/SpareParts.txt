As a <client> i need to be able to <buy spare parts> 


Acceptance criteria

- the system will display all available spare parts and prices directly from the data base

- the system will update the stock after any successful operation

- the system will prompt the user if a part is out of stock 

- the user will be able to manage their cart (change quantities and remove parts)

- the user will be subjected to the systems rules



completion criteria 

- user has bought spare parts successfully 

- database updates spare parts stock instantly after purchase 

- system blocks purchases when stock is empty or invalid quantity selected

- user can check order status and view their purchased part list

- system saves purchase details and applies sales policies
