# Manage Drive Appointments

As an employee, I wish to accompany the customer during the test drive to ensure vehicle safety and record observations regarding its performance.
This enhances the customer experience and allows for maintaining control over company assets.

## Acceptance criteria

* The system must allow for the viewing of scheduled test drives.
* The employee must be able to record the start and end of a test drive.
* The system must identify the customer, the responsible employee, and the vehicle involved.
* The system must validate that the vehicle is available and authorized for the test drive.
* The system must allow for recording observations regarding the vehicle's behavior and performance during the test drive.
* The system must allow for recording any damage or incidents detected during the test drive.
* The system must prevent the same vehicle from being assigned to two test drives with overlapping schedules.

## Definition of done

* [ ] A log for the start and completion of test drives has been implemented.
* [ ] A log for observations and incidents has been implemented.
* [ ] Vehicle availability and schedule validation have been verified.
* [ ] At least one automated test for the functionality has been created and executed.
